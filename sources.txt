# ============================================================================
# Upstream blocklist sources for Cloudflare Gateway DNS ad-blocking
# ----------------------------------------------------------------------------
# Format of each line:  <url> [format]
#   format is optional and one of: hosts | domains | adblock
#   if omitted, it is auto-detected from the file content.
# Lines starting with '#' are comments and ignored.
#
# Domain-only / DNS-safe feeds are preferred (no URL-filter rules). The sync
# step downloads every source, merges them, drops invalid + duplicate entries,
# removes anything in whitelist.txt, then uploads the streamlined result.
# ============================================================================

# StevenBlack — unified hosts (ads + malware). High-quality international baseline.
https://raw.githubusercontent.com/StevenBlack/hosts/master/hosts  hosts

# Anti-AD — strong coverage for Chinese / Asian ad & tracking domains.
# Domain-only list ('domains' format). Curated, low false-positive.
https://anti-ad.net/domains.txt  domains

# ----------------------------------------------------------------------------
# Optional / larger sources — uncomment to enable. Watch the total size:
# Cloudflare free Zero Trust caps you around ~300,000 blocked domains total
# (1,000 per list, ~300 lists). The sync step auto-truncates past
# CF_MAX_TOTAL_ITEMS (default 300,000). Pick a set that fits your quota.
# ----------------------------------------------------------------------------
