# 放行名单（Allowlist）—— 避免国内外常见网站因误杀而无法正常访问
# ----------------------------------------------------------------------------
# 规则说明：
#   * 每行一个域名；以 '#' 开头的行是注释，会被忽略。
#   * Cloudflare Gateway 的 DOMAIN 列表为【精确匹配】，此处放行的是各站
#     点的主域（根域）。若某站点的具体子域（如 analytics.xxx.com）被误拦，
#     请单独把该子域加进来。
#   * 本名单在整合阶段会从最终的拦截清单中减去（clean -= whitelist），
#     因此只放行确实被源清单误包含的根域，不会放行广告/追踪子域。
#   * 若需要“整站包括所有子域都放行”，更稳妥的做法是在 Cloudflare
#     Gateway 另建一条 Do Not Block 策略，而不是依赖此处（精确匹配）放行。
# ============================================================================
